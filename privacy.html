Политика конфиденциальности

Aria Bot — личное приложение одного пользователя, его владельца. Другие люди им не пользуются.

Какие данные использует приложение

  • Google Таблицы: создаёт и редактирует таблицу контент-плана владельца.
  • Google Диск: создаёт папки и файлы только внутри приложения (доступ drive.file); остальные файлы владельца приложение не видит.
  • YouTube: загружает видео на канал владельца и читает статистику его собственных видео.

Что происходит с данными

  • Данные обрабатываются только для работы приложения и принадлежат владельцу аккаунта Google.
  • Они не передаются третьим лицам, не продаются и не используются для рекламы.
  • Токены доступа хранятся на закрытом сервере владельца. Владелец может отозвать доступ в любой момент на странице myaccount.google.com/permissions.

Использование и передача информации, полученной из API Google, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Privacy policy (English)

Aria Bot is a personal application used only by its owner. It accesses Google Sheets (to maintain the owner's content plan), Google Drive (only files created by the app, scope drive.file) and YouTube (to upload videos to the owner's channel and read statistics of the owner's videos). Data is not shared with third parties, sold or used for advertising. Access can be revoked at any time at myaccount.google.com/permissions. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
